# Project: 18-Strategy Automated Stock Trading System Readiness Audit

## Architecture
- 18 Quantitative Strategies + 2D Regime Matrix (6 Regimes) + Dynamic Weighted Ensemble (Gram-Schmidt Orthogonalization, Isotonic Calibration)
- Risk Management & Crisis Gating (VIX, USDKRW thresholds, Risk Parity & Covariance Shrinkage HRP Allocation)
- Data Layer: SQLite WAL (StockPriceDB & MarketIndicatorStorage), Rate-limited Fundamentals Fetcher with 60-day Filing Lag
- Pipeline Execution: `trading_system/run_pipeline.py`
- Dashboard: `gh-pages/index.html` generated by `trading_system/generate_report.py`
- CI/CD & Automation: GitHub Actions workflows (`.github/workflows/pipeline.yml`, `.github/workflows/training.yml`)
