# GitHub Action Artifact Verifier Skill

This skill provides comprehensive instructions and automated tooling to verify the integrity and non-zero validity of stock trading prediction artifacts generated by GitHub Actions pipeline runs across **all 14 multi-factor strategies**.

## Key Verification Requirements

For each target market (**SP500**, **KOSPI**, **KOSDAQ**, **KONEX**), all 14 strategies must output valid prediction data:

| # | Strategy | Output Artifact | Non-Zero Validation Rule |
|---|----------|-----------------|--------------------------|
| 1 | **Surge Classifier** | `surge_predictions.txt` / `surge_predictions_{MARKET}.txt` | Probability values > 0.0% (not all 0.0% or empty) |
| 2 | **VCP ML Predictor** | `vcp_ml_predictions.txt` / `vcp_ml_predictions_{MARKET}.txt` | Valid predictions or explicit symbol status |
| 3 | **Regression Model** | `pipeline_result.txt` / `pipeline_result_{MARKET}.txt` | Expected return predictions count > 0 |
| 4 | **VCP Rule Detector** | `vcp_patterns.txt` / `vcp_patterns_{MARKET}.txt` | Clean execution & valid pattern listings |
| 5 | **Lead-Lag Matrix** | `lead_lag_predictions.txt` / `lead_lag_predictions_{MARKET}.txt` | Leader/follower correlation entries > 0 |
| 6 | **Stat-Arb Cointegration** | `stat_arb_predictions.txt` / `stat_arb_predictions_{MARKET}.txt` | Cointegrated pairs or fallback mean-reversion entries > 0 |
| 7 | **Sector Rotation** | `sector_predictions.txt` / `sector_predictions_{MARKET}.txt` | Relative sector momentum scores > 0 |
| 8 | **RIM Valuation** | `rim_predictions.txt` / `rim_predictions_{MARKET}.txt` | Residual income intrinsic valuation entries > 0 |
| 9 | **Event-Driven Catalyst** | `event_driven_predictions.txt` / `event_driven_predictions_{MARKET}.txt` | Disclosure/volume catalyst score entries > 0 |
| 10 | **MQ Factor** | `mq_factor_predictions.txt` / `mq_factor_predictions_{MARKET}.txt` | Momentum quality factor score entries > 0 |
| 11 | **Options IV Skew** | `iv_skew_predictions.txt` / `iv_skew_predictions_{MARKET}.txt` | Option IV skew or volatility skew entries > 0 |
| 12 | **Order Flow (MFI)** | `order_flow_predictions.txt` / `order_flow_predictions_{MARKET}.txt` | Foreign/institutional order flow entries > 0 |
| 13 | **Short-Term Reversal** | `short_term_reversal_predictions.txt` / `short_term_reversal_predictions_{MARKET}.txt` | Overbought/oversold mean reversion entries > 0 |
| 14 | **14-Strategy Ensemble** | `ensemble_predictions.txt` / `ensemble_predictions_{MARKET}.txt` | Dynamic weighted ensemble picks > 0 |

In addition:
- **Ensemble Integration**: `ensemble_predictions.txt` must be updated with 14 strategy dynamic weights and TOP 100 picks across markets.
- **GitHub Pages Dashboard**: `gh-pages/index.html` must be rendered without missing market tabs or empty state placeholders.

## Quick Start: Running the Automated Verification Tool

Run the automated verification script on downloaded GHA artifacts or local result directory:

```bash
# Verify local/merged results across all 14 strategies
.venv/bin/python trading_system/scripts/verify_gha_artifacts.py --result-dir trading_system/result --gh-pages-dir gh-pages

# Return exit code 1 on validation failure (for CI/CD steps)
.venv/bin/python trading_system/scripts/verify_gha_artifacts.py --result-dir trading_system/result --gh-pages-dir gh-pages --strict

# Output detailed JSON report
.venv/bin/python trading_system/scripts/verify_gha_artifacts.py --result-dir trading_system/result --json
```

On Windows environments:
```powershell
.venv\Scripts\python.exe trading_system/scripts/verify_gha_artifacts.py --result-dir trading_system/result --gh-pages-dir gh-pages
```

## Step-by-Step Workflow for Verifying GHA Action Runs

### Step 1: Download GHA Job Artifacts
When inspecting a GitHub Action run (e.g. `Daily Pipeline` workflow):
1. Download split market artifacts:
   - `result-SP500`
   - `result-KOSPI`
   - `result-KOSDAQ`
   - `result-KONEX`
   - `merged-results`
2. Extract files into a target directory (e.g., `trading_system/result/`).

### Step 2: Validate Data Completeness Per Market & Strategy
Inspect each market's 14 strategy prediction files:

#### A. Core Predictive Models (`surge_predictions`, `vcp_ml_predictions`, `pipeline_result`, `vcp_patterns`, `lead_lag_predictions`)
- Check that top candidates exist for target horizons.
- **Failure Condition**: File contains "데이터 없음" or missing section headers.

#### B. Multi-Factor & Valuations (`stat_arb`, `sector`, `rim`, `event_driven`, `mq_factor`, `iv_skew`, `order_flow`, `short_term_reversal`)
- Check that each strategy generates continuous non-zero scores and top 100 listings.
- **Failure Condition**: Missing strategy files or `NameError`/`KeyError` exceptions in job log.

---

### Step 3: Verify Ensemble Merging (`ensemble_predictions.txt`)
Check `merge_predictions.py` output:
1. Ensure executive market summary contains market regime (e.g., `BULL`, `BEAR`, `SIDEWAYS`).
2. Verify non-zero strategy weights across all 14 strategies.
3. Verify top 100 ensemble picks exist for target markets.

---

### Step 4: Verify GitHub Pages HTML Dashboard (`gh-pages/index.html`)
Check `generate_report.py` execution:
1. Verify `gh-pages/index.html` file size > 50KB.
2. Search for market cards (`KOSPI`, `SP500`, `KOSDAQ`, `KONEX`).
3. Verify interactive data tables load populated predictions without rendering `NaN`, `None`, or "데이터 없음".

## Common Root Causes & Troubleshooting

| Symptom | Cause | Solution |
|---------|-------|----------|
| **Surge output shows 0.0%** | `SKIP_TRAINING=True` with missing/stale model artifacts or default uncalibrated tree threshold | Ensure cached models in `trading_system/models/` are present or re-train surge classifier |
| **VCP patterns 0 found** | Strict threshold on volume contraction or narrow historical window | Verify `stock_prices.db` has sufficient historical OHLCV data |
| **Strategy 6~14 empty / 데이터 없음** | Python runtime exception (`NameError`, `KeyError`) inside pipeline loop | Wrap strategy execution in `try-except` isolation and use safe `.get()` dict lookups |
| **Ensemble file missing markets** | Split artifacts failed to download or `merge_predictions.py` regex match failed | Check artifact names `result-{MARKET}` and re-run `python trading_system/merge_predictions.py` |
| **GitHub Pages displays blank table** | `generate_report.py` input path misconfigured | Run `python trading_system/generate_report.py --result-dir trading_system/result --out gh-pages/index.html` |
